📁 File Organizer

A simple Python-based File Organizer that automatically sorts files into different folders based on their file types.

✨ Features

- Automatically organizes files
- Sorts files by their extensions
- Supports images, documents, videos, and other file types
- Creates folders automatically
- Simple command-line based project

🛠️ Technologies Used

- Python
- OS Module
- File Handling

📌 Project Purpose

This project was created to practice Python concepts such as file handling, directories, loops, conditional statements, and the OS module.
